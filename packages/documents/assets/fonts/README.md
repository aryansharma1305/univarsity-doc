# Embedded preview fonts

Noto Sans Regular and Bold, copyright The Noto Project Authors, SIL Open Font License 1.1.
The complete license is in OFL.txt. These files are bundled at build/deploy time; the renderer never
fetches a remote font or accepts a caller-selected asset path.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

The current synthetic fixtures use Latin text. University-required scripts and officially approved
fonts must be checked and versioned with the future official template; this preview makes no claim
of universal-script coverage.
