# Training certificate preview assets

Brand, crest and decorative seal are cropped from the design reference supplied by the user
for Phase 12A. The complete source certificate, recipient, original QR and handwritten signatures
are not committed or reproduced. Crops are static branding, not evidence of issuance; every
rendered page displays SAMPLE and blank unsigned signature lines.

UnifrakturMaguntia Book and Crimson Pro are self-hosted print fonts from Google Fonts,
licensed under the included SIL Open Font License files. Source:
https://github.com/google/fonts/tree/main/ofl/unifrakturmaguntia and
https://github.com/google/fonts/tree/main/ofl/crimsonpro.
Noto Sans uses the existing documents-package font assets and license.
All layout, dynamic text, sample QR and watermarks are structured HTML/CSS/SVG, not a poster image.
