# Admin Panel functionality audit

- Baseline: `main` = production release `21d9146` (2026-11-22). 39 navigation items
  (`apps/web/src/components/admin/nav.ts`), 277 API routes (`apps/api/src/**/*.controller*.ts`).
- Method: each item traced from the nav entry → page → API route and permission → Prisma model →
  tests (`apps/api/test/**`, `apps/web/test/**`, `apps/web/e2e/**`). A page that renders is not
  evidence of a working workflow.
- Earlier audit (Codex, 21 Nov, branch `docs/admin-panel-readiness`, base `747dcd3`) predates PRs #53–#57;
  this audit supersedes it.

Status legend: **COMPLETE** (workflow works end to end with tests) · **PARTIAL** (works, named gaps)
· **NAVIGATION ONLY** · **MISSING** · **BLOCKED** (needs a university decision; technical part noted).

## University decisions required

1. Regular examination applications: eligibility, fee and approval rules (Exam Form).
2. Result review/approval role policy (ADR-0016) to enable production review and publication.
3. Whether a School level above departments exists, and its records.
4. Course-wise eligibility for Course Completion and Migration certificates, and their templates/signatories.
5. Public disclosure fields per service (PR #55 checklist) and confirmation of independent policy approvers.
