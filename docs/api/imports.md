# Imports API (`/api/v1/imports`)

All endpoints require a staff session. Unsafe methods require `X-CSRF-Token` (see
[authentication](../architecture/authentication.md)). Errors use the standard envelope
`{ error: { code, message, requestId, details? } }`. Swagger (when enabled) documents every schema.
Architecture: [imports.md](../architecture/imports.md).

| Method & path                      | Permission                                                        | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /imports/templates/students`  | `imports.students.run`                                            | The `.xlsx` template (Instructions + Students sheets)                                                                                                                                                                                                                                                                                                                                                                                           |
| `POST /imports` (multipart)        | `imports.students.run`                                            | Upload: fields `type=STUDENTS`, `file` (.xlsx). Stores the file privately, creates the import (UPLOADED), queues parsing. `201` + import                                                                                                                                                                                                                                                                                                        |
| `GET /imports`                     | `imports.read`                                                    | History. Query: `page`, `pageSize`, `search` (file name), `status`, `type`, `createdById`, `from`, `to` (YYYY-MM-DD, UTC), `sortBy` (`createdAt`/`status`/`originalFilename`), `sortOrder`                                                                                                                                                                                                                                                      |
| `GET /imports/creators`            | `imports.read`                                                    | Staff who created imports (filter options)                                                                                                                                                                                                                                                                                                                                                                                                      |
| `GET /imports/:id`                 | `imports.read`                                                    | Status, progress, worksheets + suggestions, mapping, counts, failure, allowed `actions`                                                                                                                                                                                                                                                                                                                                                         |
| `POST /imports/:id/mapping`        | `imports.students.run`                                            | `{ worksheet, columns: { field: columnNumber \| null }, dateFormat: ISO\|DMY\|MDY, valueMaps?: { programCode?, departmentCode?, academicSessionCode?: { VALUE: id }, status?: { VALUE: STATUS } }, defaultAcademicSessionId?: id \| null }`. Value keys are trimmed, whitespace-collapsed, upper-case cell values; referenced records must exist (errors at `valueMaps.<field>.<VALUE>`). From VALIDATED it discards the validation (→ MAPPING) |
| `POST /imports/:id/validate`       | `imports.students.run`                                            | MAPPING/VALIDATED → VALIDATING (queues validation)                                                                                                                                                                                                                                                                                                                                                                                              |
| `POST /imports/:id/commit`         | `imports.students.run` + `students.write` + `registrations.write` | `{ applyUpdates: boolean }` (default false) VALIDATED → PROCESSING                                                                                                                                                                                                                                                                                                                                                                              |
| `POST /imports/:id/cancel`         | `imports.students.run`                                            | Before importing starts                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `POST /imports/:id/retry`          | `imports.students.run`                                            | FAILED with `failure.retryable` → resumes the failed step                                                                                                                                                                                                                                                                                                                                                                                       |
| `GET /imports/:id/rows`            | `imports.read`                                                    | Paginated rows. `filter`: `all`, `valid`, `warnings`, `errors`, `create`, `update`, `skip`, `imported`                                                                                                                                                                                                                                                                                                                                          |
| `GET /imports/:id/rows/:rowNumber` | `imports.read`                                                    | Source cells, normalised values, issues, current DB values, proposed changes                                                                                                                                                                                                                                                                                                                                                                    |
| `GET /imports/:id/error-report`    | `imports.read`                                                    | `.xlsx` report of rows with errors/warnings (`404` if none)                                                                                                                                                                                                                                                                                                                                                                                     |

Step endpoints return `200` with the updated import. Notable errors:

| Status | Code                         | When                                                                                         |
| ------ | ---------------------------- | -------------------------------------------------------------------------------------------- |
| 400    | `VALIDATION_FAILED`          | Bad mapping (field details: `columns.<field>`, `worksheet`), nothing to commit, wrong `type` |
| 400    | `UNSUPPORTED_FILE`           | Not an `.xlsx` workbook (extension, MIME type or structure)                                  |
| 403    | `FORBIDDEN` / `CSRF_INVALID` | Missing permission / CSRF token (checked before the upload is read)                          |
| 404    | `NOT_FOUND`                  | Unknown import/row, no report                                                                |
| 409    | `CONFLICT`                   | Not allowed in the current state, or the import changed concurrently                         |
| 413    | `FILE_TOO_LARGE`             | Larger than `IMPORT_MAX_FILE_MB`                                                             |
| 503    | `SERVICE_UNAVAILABLE`        | Queue unreachable; the import was kept as FAILED (retryable)                                 |

`counts` = `{ total, valid, warnings, errors, create, update, unchanged, imported, skipped, created, updated }`
where `valid + warnings + errors = total` and `create + update + unchanged` = importable rows.
